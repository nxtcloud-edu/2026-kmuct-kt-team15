## 설계 결정

설계 결정은 SPEC에 있다. 계획에 영향을 주는 것만 다시 적는다.
- **7절 API 계약이 먼저 고정돼 있다.** 그래서 화면(C 레인)을 백엔드와 병렬로 시작할 수 있다.
- **판정 엔진은 순수 함수다.** 그래서 DB 없이 가장 먼저, 따로 테스트할 수 있다.
- **레인은 파일 기준으로 나눈다.** 여러 사람이 같은 파일을 동시에 고치지 않게 하기 위해서다. 가로로 나눈 모양이지만, 레인마다 끝에 화면과 연결해 확인하는 체크포인트를 둔다.
- **SQLite에 동시에 쓰지 않는다.** 데이터 준비 배치는 JSON 파일로 따로 쓰고 한 번에 합친다.
