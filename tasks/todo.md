# 작업 목록

`SPEC.md`를 입력으로 한다. 각 작업은 처음 보는 사람이나 에이전트가 이 작업 항목, `CLAUDE.md`, `SPEC.md`만 읽고 할 수 있게 썼다.
- 작업을 끝내면 제목 아래 체크박스를 채우고 소요 시간을 적는다.
- 작업 중에 spec이 모자라거나 틀린 것을 발견하면 코드와 함께 `SPEC.md`도 고친다.
- `P`, `D`로 시작하는 작업은 오늘 준비 단계에만 한다. 당일에는 DB와 문서를 가져가므로 `T` 작업만 다시 한다.
- **화면은 `docs/ui-spec.md`로 만든다.** 시안 HTML은 당일 가져갈 수 없어서 글로 옮겼다. `docs/ui-mockup.html`은 읽지 않는다.
- **9/19 밤 UI (2) 반영:** UI 시안이 `UI (2)`로 바뀌어 T 작업을 새 시안 기준으로 고치고 체크박스를 비웠다. 바뀐 점은 SPEC 13절 끝의 표에 있다. 1회차 리허설의 결과와 확인 내용은 `tasks/log.md`와 git 기록에 있다. D 작업은 D6까지 9/19 밤에 끝냈다(D5 팀 점검만 남았다).
